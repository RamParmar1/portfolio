## 🛠️ Technology Stack

This application is built with modern, high-performance web technologies:

- **React 19** - For building a dynamic and interactive UI.
- **Vite** - Lightning-fast frontend build tooling.
- **Tailwind CSS** - Utility-first styling with custom glassmorphism and a beautiful dark mode.
- **Lucide React** - Clean, consistent iconography.
- **TypeScript** - For robust type safety and maintainable code.

## ✨ Premium Features

- **Glassmorphic UI:** High-end translucent components with beautiful hover states and animations.
- **Dynamic Theme Toggling:** Seamless transition between Light and Dark mode.
- **Responsive Design:** Flawless experience across mobile, tablet, and desktop viewports.
- **Performance Optimized:** Uses Vite's efficient bundling for maximum speed.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd mine-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
